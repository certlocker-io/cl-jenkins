Authenticate this build using OIDC and bind Trust passwords, credentials, configuration, PEMs or private keys. Use ENV for text, or FILE to receive the path to a private temporary file on the current agent. FILE bindings require a node block. Field selection extracts values such as password, username or key from structured secrets. Variables and files are scoped to the body; files are deleted after it ends. Values are masked in the body console. The temporary API token is handled internally. See the plugin README for recipes and security limitations.
